**Co se naučíte:** kam ukládat práci, aby ji Kolegové i agenti později
našli.

Chat je pracovní rozhovor. Agenti ho berou jako mezipaměť: co zůstane jen
v chatu, je pro všechny ostatní ztracené. Každý druh výsledku má svůj
domov:

| Co | Kam patří |
| --- | --- |
| Sdílené znalosti: postupy, souvislosti, co se při práci ukázalo | Knowledgebase Organizace |
| Plány, jejich stav a kdo za ně odpovídá | Mission Control Organizace |
| Otevřený problém nebo nejistota | GitHub Issue v repozitáři, kterého se týká |
| Software a dokumentace | repozitář na GitHubu, změna přes pull request |
| Hotový soubor, který nepatří do žádného repozitáře, třeba prezentace | Soubory Prostředí |
| Osobní věci | vaše Osobní Prostředí, nikdy Pracovní |

Každá změna repozitáře jde jako pull request. Když repozitář můžete jen
číst, agent v něm zapíše návrh jako issue a zmíní, kdo může změnu provést.
Vaše Organizace může své moduly jmenovat jinak; agent je najde v jejích
vlastních instrukcích a dokumentech.

## Váš úkol

Vyberte jednu věc ze své nedávné práce, kterou by potřeboval znát nový
Kolega: pojem, krok postupu nebo pravidlo. Zapište ji dvěma nebo třemi
větami. Pak pošlete v Chatu:

```text
Chci tohle uložit pro Kolegy: [vaše dvě nebo tři věty].
Řekni mi, kam to v naší Organizaci patří (Knowledgebase, Mission
Control, issue, nebo Soubory) a proč. Ověř, jestli už něco podobného
neexistuje. Zatím nic neukládej.
```

**Hotovo poznáte takto:** máte jednu malou skutečnou práci a víte, kam
patří. Uložit ji necháte v lekci 7.
