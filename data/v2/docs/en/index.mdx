Lazurio is a developer-stage local coordination layer for work done by people
and AI agents. Today it is a public Git repository containing a CLI/Core,
Launchpad, diagnostics, operating rules and a structure for mounting separate
company repositories called Organizations. It is not an AI model, a managed
SaaS tenant or a hard isolation layer around the selected agent client.

The current supported setup path is a source checkout using Git and Bun. The
CLI is version 0 and experimental; a simple packaged installation is a target,
not a released distribution. Source is currently available under
[FSL-1.1-Apache-2.0](https://github.com/HumanAndMachines/Lazurio/blob/3c5bda5d54c5556a0e54f3c339d988aa911fda60/LICENSE.md),

license link and copyright notices. A Competing Use means making the software
available to others in a commercial product or service that substitutes for

Lazurio keeps companies in separate repositories, takes repository authority
from GitHub and other provider grants, and makes consequential changes
reviewable before publication. These rules improve governance; they do not
make an endpoint, model or integration safe by themselves.
