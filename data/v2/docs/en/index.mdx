Lazurio is a working environment and operating model for collaboration between
people and AI agents. It gives that collaboration an explicit shape: companies
are separated into Organizations, work lives in versioned repositories, access
comes from the systems that already own it, and consequential changes stay
reviewable before publication. The public source describes both the target
[architecture](https://github.com/HumanAndMachines/Lazurio/blob/69c53ec342124aef48cb9d04fd109f9886ec242e/ARCHITECTURE.md)
and the current [collaboration rules](https://github.com/HumanAndMachines/Lazurio/blob/69c53ec342124aef48cb9d04fd109f9886ec242e/AGENTS.md).

It is not a promise that an AI system can safely do anything. It is a framework
for making authority, context, work and publication boundaries visible enough
to govern.
