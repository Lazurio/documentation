Lazurio is a working environment and operating model for collaboration between
people and AI agents. It gives that collaboration an explicit shape: companies
remain separate Organizations, work lives in versioned repositories, access
comes from the systems that already own it, and consequential changes stay
reviewable before publication.

Today Lazurio runs from a public source checkout using Git and Bun. It includes
Launchpad, diagnostics, an experimental CLI v0 and the operating contracts used
by connected Organizations and modules. A simple packaged installation is a
target, not a released distribution.

Lazurio is not an AI model, a managed SaaS tenant or a universal security
sandbox around the agent client. Its value is narrower and more practical: it
makes authority, context, work and publication boundaries visible enough to
govern. The [English control evidence](/en/public-evidence/) shows where those
claims come from and what they do not prove.

## Choose your path

- **Deciding whether to allow it:** read the [ten-minute IT
  briefing](/en/it-administrators/) and the [data-access
  review](/en/data-access-security/).
- **Understanding the mechanics:** see [how Lazurio
  works](/en/how-lazurio-works/) and how it is [deployed and
  operated](/en/deployment-operations/).
- **Checking the underlying claims:** use the [English control
  evidence](/en/public-evidence/) and its links to the exact public source.
- **Comparing alternatives:** use the sourced [Lazurio vs Microsoft
  Copilot](/en/lazurio-vs-microsoft-copilot/) decision guide. They solve
  overlapping, but not identical, problems.
- **Letting an agent read the docs:** give it `/llms.txt` or
  `/content-index.json`. Both come from the same reviewed pages people read.
