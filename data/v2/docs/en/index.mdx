Lazurio is a local working system in which people and AI cooperate across
companies, projects and personal work without collapsing their repositories,
data and permissions into one store. It supplies the structure, operating
rules, diagnostics and Launchpad that let a Task Agent work inside a clearly
named context.

The model resembles open-source collaboration at organization scale. An
Organization has maintainers, contributors, repository grants and review
rules. Its Modules remain separate repositories with their own owners and
lifecycle, while Lazurio presents the authorized set as one coherent working
environment. The result feels monorepo-like to a builder without becoming one
giant repository or a second permission system.

## The system in four slices

```text
Administration
Dashboard → account → Organization → Marketplace → Colleagues and grants

Daily work
AI app / Task Agent ↔ Lazurio Root ↔ Organization ↔ Module repositories

Builder surface
Launchpad → discover Modules → inspect status → start or open development apps

Authority
GitHub identity + Teams + repository grants + branch rules → allowed actions
```

These slices connect, but they are not interchangeable:

- **Dashboard** is the starting and administrative surface for Lazurio
  accounts, Organizations, Marketplace Modules, Colleagues, permissions, AI
  Colleague Machines, hosting and operational visibility. It is developed and
  deployed separately from the public Lazurio Root.
- **Launchpad** is the builder-first surface on a Machine. It discovers the
  Organizations and Modules available in that Root and manages local
  development application lifecycle.
- **An AI app** hosts the current Task Agent session. Lazurio is not the model
  and does not give the session new permissions.
- **GitHub and connected providers** remain the live access authorities.

## What is available now

| Capability | Current state |
| --- | --- |
| Source Root with Git and Bun | Supported development path |
| Launchpad and Organization discovery | Available in the public source |
| CLI/Core v0 | Available, experimental and not a stable public API |
| Desktop Launchpad installer | Available on macOS and Windows |
| Packaged CLI and generated Managed Root | Target architecture, not the current distribution |
| Dashboard | Separately developed product surface, not runtime authority for Launchpad |
| Native Lazurio MCP server | Not included in the current release |

The public Lazurio source uses
[FSL-1.1-Apache-2.0](https://github.com/HumanAndMachines/Lazurio/blob/08d21803d4d4011304e1181ecf02ab9c5bfbad58/LICENSE.md).
It is source-available today and receives the Apache 2.0 future license on the
schedule defined in that license. Do not describe the current Lazurio release
itself as OSI open source.
