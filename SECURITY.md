# Security policy

Please do not disclose credentials, personal data, customer data, private
topology or an exploitable security issue in a public GitHub issue.

Use GitHub's private security advisory flow for this repository:

<https://github.com/Lazurio/documentation/security/advisories/new>

For ordinary documentation errors that contain no sensitive material, open a
public issue and include the page URL, the incorrect claim and a public source
that supports the correction.
